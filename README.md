# AI Fashion

AI-платформа для гардероба: цифровой гардероб, AI-стилист, подбор образов по календарю и погоде, маркетплейс и покупка готового образа одной кнопкой.

**Веб-демо:** https://iluashakapusta.github.io/ai-fashion/ — открывается на телефоне и компьютере, можно отправлять инвесторам.

**План запуска:** подписка, платежи, магазины приложений, законы — [docs/LAUNCH.md](docs/LAUNCH.md).

## Что есть в демо

| Раздел | Что можно сделать |
| --- | --- |
| **Сегодня** | Погода и совет по одежде, образ на день из своих вещей, события из календаря с кнопкой «Подобрать образ» |
| **Лента** | Два раздела: «Новости» (тренды, гиды, новости приложения) и «Сообщество» — образы пользователей, тематические каналы с подпиской, публикация своего образа, лайки, «Собрать похожий», жалоба и скрытие автора |
| **Гардероб** (в профиле) | 25 вещей, поиск, фильтры, карточка вещи (цена одного выхода, с чем носить), анализ «чего не хватает», аналитика для Premium |
| **Новая вещь** | Фото с камеры или из галереи → удаление фона и распознавание → правка типа, цвета, стиля, сезона → «сочетается с N вещами, +M образов» |
| **AI-стилист** | Запрос обычными словами: отпуск, неделя, свидание, собеседование, «обновить гардероб за 20 000 ₽», образ вокруг конкретной вещи. Учитывает бюджет, количество образов, дни, климат |
| **Образ** | Вещи из гардероба и из маркета, замена любого элемента, итог по продавцам и срокам доставки, «Купить весь образ» |
| **Маркет** | Сверху — раздел «Магазины» (подписки первыми) со страницей магазина. Каталог магазинов, брендов, частных продавцов и внешней площадки, сортировка «под мой гардероб», избранное. Реклама вынесена в отдельный подписанный блок |
| **Корзина и заказы** | Проверка наличия, цен и доставки, одна оплата → отдельный заказ у каждого продавца, статусы обновляются сами |
| **Premium** | Экран подписки: 1, 3, 6 и 12 месяцев (699 / 1 790 / 3 290 / 5 870 ₽), пакет «Отпуск», лимит 3 запроса к стилисту в день без подписки, кэшбэк и бесплатная доставка с подпиской |
| **Профиль** | Мой гардероб, Premium, заказы, корзина; «Источники данных» и «Уведомления» раскрываются по нажатию; сброс демо |

### Что пока имитируется

- Гардероб, товары, продавцы, погода и события календаря — демо-данные (`src/data/demo.ts`).
- AI-стилист — правила на устройстве (`src/engine/stylist.ts`): разбор запроса, подбор сочетаний по цвету, стилю и сезону, докупка недостающего в рамках бюджета. Интерфейс движка (`parseRequest` → `planLooks` → `alternatives`) рассчитан на замену LLM-сервисом.
- Распознавание вещи и удаление фона показаны анимацией с заранее заданным результатом.
- Оплата не проводится, состояние сбрасывается при перезагрузке страницы.

## Технологии

- [Expo](https://expo.dev) SDK 54 + React Native + Expo Router: одна кодовая база для iOS, Android и веба.
- TypeScript, иконки вещей — SVG.
- Оформление — `src/theme.ts`: один сдержанный стиль (льняной белый, тёмно-синий, золото; Playfair Display + Jost).

```
src/
  app/          экраны (файловая навигация Expo Router)
    (tabs)/     Сегодня, Лента, Стилист, Маркет, Профиль
    item/       новая вещь, карточка вещи
    look/       образ
    product/    товар
    channel/    канал ленты
    post/       публикация образа
    shop/       страница магазина
    wardrobe.tsx, cart.tsx, orders.tsx, premium.tsx
  components/   UI-компоненты
  data/         типы и демо-данные
  engine/       логика стилиста и совместимости вещей
  store/        состояние приложения
```

## Запуск

```bash
npm install
npm run web        # в браузере
npm start          # QR-код для Expo Go на телефоне
npm run typecheck
npm run lint
```

## Публикация веб-версии

Каждый push в `main` собирает веб-версию и выкладывает её на GitHub Pages (`.github/workflows/deploy-web.yml`).
Один раз нужно включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Следующие этапы

1. Бэкенд: аккаунты, хранение гардероба и фото, каталог продавцов, заказы.
2. Настоящий AI: распознавание вещей и удаление фона, LLM-стилист на месте `src/engine/stylist.ts`.
3. Интеграции: Google / Apple Календарь, геолокация и прогноз погоды, push-уведомления.
4. Платежи: провайдер с СБП и «Мир» для маркетплейса, подписка через сайт и магазины приложений.
5. Сборка для App Store, Google Play, RuStore и AppGallery через EAS Build.
